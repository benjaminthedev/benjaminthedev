## Public work

Built two React apps for the West Midlands Combined Authority (WMCA): the disruptions section, with a map and live disruption data for bus, train, and tram, and an opportunities app for filtering by age, postcode, eligibility, and industry. Oct 2019 – Apr 2020.

- Set up the disruptions React app and got the map working for bus, train, and tram. [wmn-disruptions](https://github.com/wmcadigital/wmn-disruptions)
- Built search, autocomplete, and list views, with disruption indicators from the API, a date and time picker, and disruption HTML sanitised with DOMPurify before it was rendered.
- Built the opportunities app in React, Redux, and React Router, with filters for age, postcode, eligibility, industry, skill level, and opportunity type, and a detail view for each opportunity. [WMCA-Opportunities-App](https://github.com/wmcadigital/WMCA-Opportunities-App)

Also public: [nextReactInvoicing](https://github.com/benjaminthedev/nextReactInvoicing), a TypeScript invoicing app with customers, VAT, and PDF generation. React, Vite, Tailwind, MongoDB, and Vercel.
